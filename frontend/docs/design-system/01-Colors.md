# Color System

Our color system uses a highly controlled palette mapped via `tailwind.config.js`.

## Primary (Teal)
Used for the brand, primary actions, active states, and emphasis.
- **Teal 50 (`#f0fdfa`)**: Subtle backgrounds (e.g., hover states for outline buttons, active menu states).
- **Teal 100 (`#ccfbf1`)**: Soft highlights or borders.
- **Teal 500 (`#14b8a6`)**: Icons and secondary highlights.
- **Teal 600 (`#0d9488`)**: **Primary Interactive Color** (Buttons, Links).
- **Teal 700 (`#0f766e`)**: Hover states for Primary Buttons (active/focus).

## Neutrals (Slate)
Used for backgrounds, text, and structure.
- **White (`#ffffff`)**: Component backgrounds (Cards, Modals, Inputs).
- **Slate 50 (`#f8fafc`)**: Main application body background.
- **Slate 100 (`#f1f5f9`)**: Subtle borders, dividers, secondary button backgrounds.
- **Slate 200 (`#e2e8f0`)**: Standard component borders, Skeleton loaders.
- **Slate 400 (`#94a3b8`)**: Disabled states, placeholder text.
- **Slate 500 (`#64748b`)**: Secondary text (subtitles, descriptions).
- **Slate 800 (`#1e293b`)**: Standard body text.
- **Slate 900 (`#0f172a`)**: Primary headings, extremely high contrast text.

## Semantic Colors
- **Error/Destructive**: Red 600 (`#dc2626`). Used for delete buttons, error messages, invalid inputs.
- **Warning**: Amber 500 (`#f59e0b`). Used for alerts, missing info, tips.
- **Success**: Green 600 (`#16a34a`). Used for success toasts, completed states, approval badges.
